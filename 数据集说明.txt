【一、数据集概述】

VisDrone2019-DET 是一个大规模无人机航拍目标检测数据集，由天津大学 AISKYEYE
团队发布。数据集包含从中国 14 个不同城市（市区 + 郊区）无人机拍摄的航拍图像，
涵盖不同场景、天气和光照条件，是目前最具代表性的无人机视角检测基准之一。

  数据来源：VisDrone2019 Object Detection in Images
  论文引用：Zhu et al., "Vision Meets Drones: Past, Present and Future", 2021
  项目用途：面向 VisDrone 高密度小目标场景的下一代 DETR 架构研究

【三、10 个目标类别】

  VisDrone 原始标注有 11 个 ID（0-10），其中 ID=0 为"忽略区域"已过滤，
  ID 1-10 映射为 YOLO 格式的 0-9：

  ┌──────────┬────────────────────┬──────────┬──────────┬──────────┐
  │ YOLO ID  │ 类别（英文）       │ 类别（中文）│ 训练集   │ 占比     │
  ├──────────┼────────────────────┼──────────┼──────────┼──────────┤
  │ 0        │ pedestrian         │ 行人     │  79,337  │ 23.1%    │
  │ 1        │ people             │ 人群     │  27,059  │  7.9%    │
  │ 2        │ bicycle            │ 自行车   │  10,480  │  3.1%    │
  │ 3        │ car                │ 轿车     │ 144,867  │ 42.2%    │
  │ 4        │ van                │ 面包车   │  24,956  │  7.3%    │
  │ 5        │ truck              │ 卡车     │  12,875  │  3.8%    │
  │ 6        │ tricycle           │ 三轮车   │   4,812  │  1.4%    │
  │ 7        │ awning-tricycle    │ 带蓬三轮 │   3,246  │  0.9%    │
  │ 8        │ bus                │ 公交车   │   5,926  │  1.7%    │
  │ 9        │ motor              │ 摩托车   │  29,647  │  8.6%    │
  └──────────┴────────────────────┴──────────┴──────────┴──────────┘

  类别严重不均衡：轿车占 42%，是第二大类（行人 23%）的近两倍。
  稀有类（tricycle、awning-tricycle、bus）合计不到 4%，是检测难点。


【四、YOLO 标注格式】

  每张图片对应一个同名的 .txt 标注文件，位于 labels/ 目录下。
  每行一个目标，格式为：

      class_id  cx  cy  w  h

  其中所有坐标均为归一化值（除以图片宽高，范围 [0, 1]）：

  - class_id：类别索引（0-9）
  - cx, cy：边界框中心点的 x, y 坐标
  - w, h：边界框的宽度、高度

  示例（图片 0000001_00001_d_0000001.jpg 的标注）：
    0  0.4523  0.3215  0.0234  0.0456
    3  0.6789  0.5123  0.0567  0.0890
    ...


【五、图片特征】

  - 采集设备：无人机搭载摄像头
  - 拍摄高度：5-100 米不等
  - 图片分辨率：约 2000×1500 像素（训练时 resize 到 640×640）
  - 视角：俯视 / 斜视，涵盖城市街道、广场、公园、居民区等
  - 天气条件：晴天、阴天、夜间均有覆盖
  - 目标尺度：大多数目标为小目标（< 32×32 像素），占比超 70%
  - 高密度场景：单张图片目标数可达 80+，遮挡、重叠严重
